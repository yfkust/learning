## 免密码登入

[公钥验证](https://zhida.zhihu.com/search?content_id=984514&content_type=Article&match_order=1&q=公钥验证&zd_token=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3MiOiJ6aGlkYV9zZXJ2ZXIiLCJleHAiOjE3OTAyNTU0NjYsInEiOiLlhazpkqXpqozor4EiLCJ6aGlkYV9zb3VyY2UiOiJlbnRpdHkiLCJjb250ZW50X2lkIjo5ODQ1MTQsImNvbnRlbnRfdHlwZSI6IkFydGljbGUiLCJtYXRjaF9vcmRlciI6MSwiemRfdG9rZW4iOm51bGx9.e3IFQrwlf5XqxPa8OPBa3bFBvGOt_5151g7KFspP8Hw&zhida_source=entity) 实现免密码登入，设置 SSH 钥匙。

执行 ssh-keygen 即可生成 SSH 钥匙，一路回车即可。Windows 用户可以使用 [PuTTY](https://link.zhihu.com/?target=http%3A//www.chiark.greenend.org.uk/~sgtatham/putty/download.html) 配套的 *PuTTYgen* 工具。

```text
ssh-keygen
```

生成的公钥放在了 ~/.ssh/id_rsa.pub，私钥放在了 ~/.ssh/id_rsa。

或者自主命名：

```text
ssh-keygen -t ed25519 -C ""
```

~/.ssh 目录下应该有：

id_ed25519
id_ed25519.pub

接下来，让远程机器记住我们的**公钥**。

输入：

```text
 ssh-copy-id user@remote -p port
```

在没有 [ssh-copy-id](https://zhida.zhihu.com/search?content_id=984514&content_type=Article&match_order=8&q=ssh-copy-id&zd_token=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3MiOiJ6aGlkYV9zZXJ2ZXIiLCJleHAiOjE3OTAyNTU0NjYsInEiOiJzc2gtY29weS1pZCIsInpoaWRhX3NvdXJjZSI6ImVudGl0eSIsImNvbnRlbnRfaWQiOjk4NDUxNCwiY29udGVudF90eXBlIjoiQXJ0aWNsZSIsIm1hdGNoX29yZGVyIjo4LCJ6ZF90b2tlbiI6bnVsbH0.U1-s0ETQxyfm1bfCjNb8-tGZQUtAhWnFZ5gmlA3tBNA&zhida_source=entity) 的情况下（比如在 Windows 上，命令：

```text
ssh user@remote -p port 'mkdir -p .ssh && cat >> .ssh/authorized_keys' < ~/.ssh/id_rsa.pub
```

即在远端执行新建 .ssh 文件夹，并把本地的 ~/.ssh/id_rsa.pub （也就是公钥）追加到远端的 .ssh/authorized_keys 中。



## 配置别名

在 ~/.ssh/config 里面追加以下内容：

```text
Host lab
    HostName remote
    User user
    Port port
```

保存之后，即可用 ssh lab 登入。
